Independent native After Effects effect with color-region detection, six detection
quality levels, mask preview, boxes/fills/gaps, XY coordinate labels, three center
markers, curved/dashed connections, arrows and transparent graphics output.

Includes Windows x64 installer, portable package and diagnostic report collection.

**Preview limitations:** not loaded or visually compared in After Effects yet.
The CPU renderer supports 8/16 bpc; GPU, 32-bpc and MFR support are not advertised.
Original CPU detection rules, quality sampling, defaults and font metrics are not
fully recovered. Functional controls are implemented, but exact visual/temporal
parity and performance parity are not certified. Existing Tracery projects are
not migrated. Additional text types and text backgrounds are deferred.

Close AE, run the setup, reopen AE and find **Effects > Nasaat > GlitchTrace**.
See HOST_CHECKS.md and the README before using the preview in a production project.
